AARUVO LOGO PACKAGE
===================
Source: exact image supplied in chat.
Source dimensions: 2048 x 746px, transparent PNG.

01_Individual_Icon_PNG
- Requested 32, 48, 64, 128, 192, 256, 512, 1024 px icon files
- Transparent backgrounds
- Aspect ratio preserved; standard exports use a safe transparent margin
- Master tight crop included

02_Full_Horizontal_Logo
- Original exact source PNG
- Tight transparent crop
- Responsive 320, 480, 768, 1024, 1440 and 1920 px width exports

03_SVG_Vector
- *exact-svg-wrapper.svg = exact source pixels packaged in SVG (pixel-perfect)
- *vector-traced.svg = true vector silhouette approximation using traced paths and solid source colors

04_Web_Extras
- favicon.ico with multiple embedded sizes

Important: The exact SVG wrapper is pixel-perfect but internally contains the PNG.
The traced SVG is actual vector and scales without raster pixelation, but very subtle raster antialias/color variation is simplified to solid brand colors.
